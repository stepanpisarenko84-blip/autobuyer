СБОРКА ЧЕРЕЗ GITHUB (без установки чего-либо):
1. Создай новый репозиторий на github.com.
2. Загрузи в него СОДЕРЖИМОЕ этой папки (включая скрытую папку .github), не сам zip.
3. Открой вкладку Actions -> Build mod -> дождись зелёной галочки (3-10 минут).
4. Внизу запуска, в разделе Artifacts, скачай autobuyer-jar -> autobuyer-1.0.jar.
5. Положи jar в .minecraft/mods и запускай клиент Forge 1.16.5. Клавиша R - вкл/выкл.

СБОРКА НА СВОЁМ КОМПЬЮТЕРЕ: нужен установленный Gradle 7.6.4 и JDK 17:
  gradle build
(файлов gradle/wrapper в архиве нет, поэтому gradlew/gradlew.bat не работают.)
Результат: build/libs/autobuyer-1.0.jar

НАСТРОЙКИ - в начале AutoBuyer.java:
  SELL_FROM_MENU_FIRST  - как продавать: клик по ресурсу в меню скупщика (true) или по предмету в инвентаре (false).
                          Если способ не работает, мод сам переключится на второй.
  SELL_DELAY_TICKS      - пауза между кликами при продаже.
  BUY_DELAY_TICKS, BUY_CLICKS_PER_TICK, BUY_SHIFT_CLICK - скорость покупки.
  BUY_STACKS_PER_ITEM   - сколько стаков каждого ресурса набирать за проход.

ОТЛАДКА: открой любое меню сервера и нажми K - в чат выведутся слоты и названия предметов.
Если сервер кикает за спам кликами - увеличь BUY_DELAY_TICKS / SELL_DELAY_TICKS.
